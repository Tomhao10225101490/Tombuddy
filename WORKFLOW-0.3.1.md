## Authorized change
User explicitly requests default maximum tool permissions without per-operation approvals, no conversation/tool-round ceiling, and no Claude Code/Codex brand-specific task restrictions. This supersedes 0.3's mandatory individual approvals and 12-round batch limit. Do not claim root, bypass macOS/service-provider controls, unlimited context, or universal model capability.

## Acceptance / safety boundaries
- New chats and absent mode default to Full Access; explicit Manual still prompts; Plan remains read-only with explicit plan review before execution.
- Full Access uses existing current-user shell (NOT sandboxed), can affect files outside selected project; prominently disclose. File tools retain selected-project/sensitive-path protections. Model credentials remain encrypted and renderer-isolated; shell is not a credential-security boundary.
- No artificial tool-round limit. Continue until actual model completion, stop, output/context exhaustion or error. Keep command 30-second timeout, abort/process-group termination, request timeouts and strict streaming validation. No automatic network retries or output-limit continuation/paid probes.
- No application task-category/company-policy filter added; provider refusals remain provider behavior. Preserve actual evidence/public summaries rather than fabricated hidden thought.
- Test Full actual write/shell without approval, Manual approval/refusal, Plan denial, >12 signed tool rounds and restart context, stop during continuous work, immutable request mode, bad mode fail-closed. All synthetic isolated fixtures; existing paid-test marker must remain untouched.
- Run core/build and all desktop suites; back up private state outside repo and installed app; install and rerun suites/default-profile checks; archive final bytes and record hashes.
